# Aile Akademi

Türkçe, mobil uyumlu Aile Akademi PWA uygulaması. Üç öğrenci profili içerir: Elif (6. sınıf, LGS), Ahmet (10. sınıf, YKS Eşit Ağırlık) ve Bilge (11. sınıf, YKS Eşit Ağırlık).

## Kullanım

Bu depo derlenmiş statik PWA çıktısını içerir. `index.html` kök dizindedir ve Vercel gibi statik hosting servislerinde build komutu olmadan yayınlanabilir. Veriler tarayıcı LocalStorage alanında tutulur; uygulama içindeki yedekleme özelliğiyle JSON olarak dışa aktarılabilir.
